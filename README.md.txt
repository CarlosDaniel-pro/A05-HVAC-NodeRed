# A05 - Sistema de Climatización HVAC Industrial

## Descripción
Proyecto desarrollado en Node-RED para simular y supervisar un sistema de climatización HVAC industrial mediante MQTT y HiveMQ.

## Tecnologías utilizadas
- Node-RED
- MQTT
- HiveMQ
- JSONata
- HTML, CSS y JavaScript
- Git y GitHub

## Funcionalidades
- Monitoreo de temperatura y humedad.
- Control de encendido y apagado.
- Configuración de temperatura objetivo.
- Modos de operación automático, ECO y manual.
- Visualización de potencia de enfriamiento y ventilación.
- Generación y reconocimiento de alarmas.
- Indicadores de rendimiento e históricos.
- Simulación de fallos y recuperación del sistema.

## Configuración
1. Abrir Node-RED en http://localhost:1880.
2. Importar el archivo flows.json.
3. Configurar el broker MQTT broker.hivemq.com en el puerto 1883.
4. Desplegar los flujos mediante Deploy.
5. Abrir el dashboard en http://localhost:1880/hvac.

## Control de versiones
Este proyecto utiliza Git y GitHub para registrar cambios, publicar versiones mediante push y recuperar actualizaciones mediante pull.
